# Public release scope

This is a curated public companion to the private `seshat_Journal` development archive. It starts with a fresh Git history and publishes original synthetic method code, a mechanism demo, meaningful tests, method/protocol documentation, and sanitized aggregate experimental evidence.

It excludes credentials, account tokens, subscription URLs, SSH material, local absolute paths, HPC host configuration, personal conversation payloads, model weights, raw predictions, CUDA trace payloads, runtime logs, and vendored third-party repositories. The active experiment and its frozen source hashes are unchanged.

The English-language content is written for research review. Historical operational records stay in the private archive in their original language to preserve their integrity. This release does not claim to translate or republish that archive's logs or benchmark text.

Aggregate results are derived from the completed synthetic pilot; incomplete real-data scores are excluded from the public release. Source-module hashes and import adaptations appear in `source_manifest.json`. Historical audit metadata describes prior verification but does not expose the underlying traces; readers cannot independently reopen those omitted trace files from this release.

All released method modules are project-owned. External resources are linked, not redistributed. The release does not claim journal acceptance, a DOI, general semantic-token compression, or state-of-the-art public-benchmark performance.
